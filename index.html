About Us

We are revolutionizing cybersecurity by using blockchain to democratize password security tasks and rewards. Unlike traditional forums or websites that claim to crack passwords for a fee without transparency, our platform enables direct participation in solving encrypted password hashes. Blockchain ensures that the process is secure, transparent, and tamper-proof, eliminating the need for unreliable intermediaries. Our system allows experts to test the strength of their password hashes while ensuring rewards are securely managed through smart contracts. By leveraging these tools, we aim to create a more secure, transparent, and decentralized approach to password protection, offering a trustworthy alternative to current services..

Faq

There are many tools. We recommend hashcat. It has many modes of use, such as dictionary attacks or mask attacks. In this example we will show the use of mask attacks.
 
Prerequisites
1 - Installing Hashcat
    Download and install Hashcat from its official site: https://hashcat.net/hashcat/
2 - Test hashcat working
    Linux: ./hashcat.bin --version
        v6.2.6
    Windows: hashcat.exe --version
        v6.2.6
3 - An MD5 hash to crack
    For example: 5d41402abc4b2a76b9719d911017c592 (hash of "hello").
4 - Run hashcat, which will try to match 5 letters between "a" and "z"
    Linux: ./hashcat.bin -a 3 -m 0 "5d41402abc4b2a76b9719d911017c592" ?l?l?l?l?l
    Windows: hashcat.exe -a 3 -m 0 "5d41402abc4b2a76b9719d911017c592" ?l?l?l?l?l
